\# Credit Card Approval System



\## Objective

To automate credit card approval using machine learning.



\## Features

\- Prediction (Approved/Rejected)

\- Probability

\- Top influencing factors



\## Tech Stack

\- Python

\- Flask

\- Scikit-learn



\## How to Run

1\. Install requirements

2\. Run python app.py

3\. Open browser



\## Output

Web-based prediction system
